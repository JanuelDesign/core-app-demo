# CORE · App Demo

Demo interactivo de CORE, la plataforma B2B de private label de pisos de CPF Floors y Panamá Core.

Es un sitio estático (un solo `index.html`), sin build ni dependencias.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo, por ejemplo `core-app-demo`.
2. Sube todos los archivos de esta carpeta a la rama `main`.
3. Ve a **Settings → Pages → Build and deployment**: Source `Deploy from a branch`, rama `main`, carpeta `/ (root)` → Save.
4. En 1 o 2 minutos queda en `https://TU-USUARIO.github.io/core-app-demo/`.

## Publicar en Vercel (opcional)

Vercel → Add New → Project → importa el repo → Framework preset `Other` → Deploy.

## Enlaces útiles

- `#home`, `#brands`, `#catalog`, `#quote`, `#orders`: abren cada sección.
- `#quick-order`: abre directo el pedido rápido por pasos.
